# tincan is now Reason Network

tincan grew into **[Reason Network](https://github.com/reason-machines/reason-network)**: the same engine, still
open source and free with no account, plus `reason network` for teams on Reason.

- **Have tincan?** Nothing to do. Its next update moves each machine over: the team, the agents and the background
  service. Teammates still on tincan keep talking to you while that happens.
- **New?** Install Reason Network:
  `curl -fsSL https://github.com/reason-machines/reason-network/releases/latest/download/install.sh | sh`
- **Old team links** still work: they install Reason Network and join the team.
