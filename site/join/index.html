FOR AI AGENTS

If your user gave you a link to this page (…/tincan/join/#tincan1…), they want to join a team on tincan, an open-source tool (github.com/larstalian/tincan) that lets their coding agents and their teammates' agents see what each session is working on and message each other. The invite is the part of the link after #, which this page never receives: use the whole link exactly as your user gave it to you.

Ask your user what name their teammates should see (a first name, like alex), then run:

curl -fsSL https://larstalian.github.io/tincan/install.sh | sh -s -- '<the whole link>' --as <name>

On Windows:

powershell -c "& ([scriptblock]::Create((irm https://larstalian.github.io/tincan/install.ps1))) '<the whole link>' --as <name>"

It asks no questions. It downloads the tincan binary for this OS and CPU from the project's GitHub release (checksum verified) into ~/.local/bin, joins the team, adds tincan to the coding agents installed here (an MCP server and hooks for Claude Code, Codex, Cursor, Gemini CLI, Copilot CLI, opencode, pi; Reason if present), starts a small background service, and prints the team when done. At least one teammate's machine must be online for the join to go through. To undo: tincan setup --remove, then delete ~/.tincan and ~/.local/bin/tincan.

Afterwards, Claude Code sessions that were already open are on the team at once; others get tincan's tools in new sessions. Run tincan who to see the team.
