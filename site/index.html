tincan

NAME

tincan - now Reason Network

DESCRIPTION

tincan grew into Reason Network: the same engine, still open source and free with no account, plus reason network for teams on Reason.

Have tincan? Nothing to do: its next update moves each machine over (the team, the agents, the background service). Old team links still work.

New? Install Reason Network.
